# Towards Robust Zero-Shot Test-Time Self-Adaptation of CTC Transformers for Out-of-Domain Long-Form Streaming ASR

Code and scripts for reproducing our upcoming paper "Towards Robust Zero-Shot Test-Time Self-Adaptation of CTC Transformers for Out-of-Domain Long-Form Streaming ASR".

[The modified ESPnet repository can be found here](https://github.com/jsan-tset/espnet_mod_self-adaptation). Please note that, for reasons of reproducibility, this is not the most recent ESPnet version, but the one that was used when these experiments started.
